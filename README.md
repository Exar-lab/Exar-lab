## 📐 How I Work

```
Spec → Tests (fail) → Implement → Tests (pass) → Refactor → Review
```

1. **Spec-Driven Development (SDD)** — define clear specs before touching code
2. **Test-Driven Development (TDD)** — failing tests first, then implementation
3. **AI-augmented cycles** — agent orchestration to accelerate without losing control
4. **Clean Architecture** — business logic isolated from infrastructure at all times
