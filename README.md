### 🧭 About me

I'm a Backend Developer and 3rd-year Systems Engineering student (Universidad Nacional de Costa Rica, expected Feb 2026), focused on building **scalable RESTful APIs and microservices in Java / Spring Boot**.

My core workflow combines:

- 🧩 **Spec-Driven Development (SDD)** — define clear technical specs before writing a single line of code.
- ✅ **Test-Driven Development (TDD)** — red, green, refactor, applied at unit and integration level.
- 🤖 **AI-driven development** — orchestrating multi-agent AI coding tools across roles (Planner / Architect / Coder / Tester / Reviewer) as a daily productivity multiplier, while keeping a human in the loop for every critical decision.

I care about clean, testable architecture more than quick hacks — Hexagonal / Clean Architecture, SOLID, and separation of concerns show up in everything I build.
